# SHAP Explainability in SentinelPM

## Overview
SentinelPM incorporates SHAP (SHapley Additive exPlanations) to explain predictions generated by tree-based ensembles (Random Forest, XGBoost) and linear baselines (Logistic Regression).

### Causality Disclaimer
> **IMPORTANT:**
> SHAP values describe statistical model attribution—how individual input features drive the model's output relative to the expected base value. **SHAP values do NOT prove physical or mechanical causation.** An industrial sensor feature exhibiting high positive SHAP attribution indicates strong predictive association within the dataset, not that physically altering that parameter will prevent failure in real machinery.

---

## Technical Approach

### 1. Preprocessing Isolation
SentinelPM pipelines couple scikit-learn feature engineering with the downstream classifier:
```
Raw Observation -> [features: SensorFeatureEngineer + OneHotEncoder + FeatureNameSanitizer] -> [model: Estimator]
```
To ensure exact feature name and index alignment:
1. The raw observation is transformed through `pipeline.named_steps["features"]`.
2. The resulting preprocessed feature matrix (with canonical sanitised names) is provided to SHAP.
3. SHAP attributions are computed on `pipeline.named_steps["model"]`.

### 2. Explainer Selection
- **Tree Ensembles (`RandomForestClassifier`, `XGBClassifier`)**:
  Utilizes `shap.TreeExplainer`, which computes exact Shapley values in polynomial time using tree traversal algorithms.
- **Linear Models (`LogisticRegression`)**:
  Utilizes `shap.LinearExplainer` with an independent background reference masker.
- **Baseline Models (`DummyClassifier`)**:
  Explanations are explicitly rejected with `ExplainabilityError` because baseline prior classifiers do not use features.

---

## Output Structure

### Individual Prediction Explanation
For each record, the explainer produces:
- `predicted_probability`: Model-assigned failure likelihood (0.0 - 1.0).
- `base_value`: Expected failure rate across reference background (~0.0339).
- `contributions`: Feature-level attribution array containing:
  - `feature_name`: Model-safe identifier (e.g. `rotational_power_w`).
  - `display_name`: Human-readable label with physical units (e.g. `rotational_power [W]`).
  - `feature_value`: Evaluated numeric measurement.
  - `contribution`: Signed SHAP value (positive increases failure risk, negative decreases risk).
  - `direction`: `"increases_risk"`, `"decreases_risk"`, or `"neutral"`.
- `top_risk_drivers`: Top positive contributors.
- `top_risk_mitigators`: Top negative contributors.
- `summary_text`: Human-readable narrative.

### Global Feature Importance
Global importance is computed by averaging the absolute SHAP values across evaluation observations:
$$I_j = \frac{1}{N} \sum_{i=1}^N |\phi_{i,j}|$$

Offline reports can be generated with:
```powershell
python -m scripts.run_explainability
```
Output report is stored at `artifacts/reports/shap_explanation_report.json`.
